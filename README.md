## 💿 Sobre o projeto

Bem-vindo ao **My World — Crossword Edition**! 💜

Este projeto foi desenvolvido como parte da **Atividade Avaliativa III — Game: Cruzadinha de Arquitetura Computacional**, da **São Paulo Tech School (SPTech)**.

O objetivo é transformar os conteúdos estudados na disciplina em um jogo interativo para auxiliar na revisão para a prova, no qual o jogador precisa descobrir termos relacionados ao funcionamento dos computadores.

E, para deixar tudo mais divertido, a identidade visual foi inspirada na era **My World (2009–2010)**, do Justin Bieber! 🎤

---

## 🎮 Como jogar?

**01.** Leia as dicas disponíveis nas seções **Horizontal** e **Vertical**.

**02.** Descubra qual conceito de Arquitetura Computacional corresponde a cada dica.

**03.** Digite as letras diretamente nas casas da cruzadinha.

**04.** Clique em **Conferir** para verificar suas respostas.

**05.** Acompanhe seu progresso pelo contador de acertos.

**06.** Quer tentar novamente? Clique em **Reiniciar**!

> 💌 Seu desafio é acertar as 16 palavras e completar a cruzadinha!

---

## 🧩 Palavras da cruzadinha

O jogo utiliza os **16 termos** previstos na atividade:

| 💜 | Conceito |
|:---:|---|
| 01 | CPU |
| 02 | ULA |
| 03 | UC |
| 04 | REGISTRADORES |
| 05 | RAM |
| 06 | ROM |
| 07 | EEPROM |
| 08 | FLASH |
| 09 | CACHE |
| 10 | MEMORIADEMASSA |
| 11 | DMA |
| 12 | ADDRESSBUS |
| 13 | DATABUS |
| 14 | MICROCONTROLADOR |
| 15 | DUALCORE |
| 16 | QUADCORE |

As palavras abordam componentes do processador, tipos de memória, barramentos e características de sistemas computacionais.
